Pharmacy System Database Project

Project Overview

The Pharmacy System is a database project designed to organize pharmacy information using PostgreSQL and SQL.

Project Objectives

- Store medicine information.
- Store customer details.
- Record sales transactions.
- Connect customers, medicines, and sales using database relationships.

Database Tables

1. Customers: Stores customer information.
2. Medicines: Stores medicine names, categories, prices, and available quantities.
3. Sales: Stores sales information and connects customers with medicines.

Project Files

- "pharmacy_system.sql" — SQL database code.
- "Pharmacy_System_Documentation.pdf" — Project documentation.
- "Pharmacy_System_ERD.png" — Entity Relationship Diagram.

Tools Used

- PostgreSQL
- pgAdmin 4
- SQL
- GitHub

Conclusion

This project demonstrates how SQL and relational databases can be used to organize pharmacy data and manage relationships between tables.
